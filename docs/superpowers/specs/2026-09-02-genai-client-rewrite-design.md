# haskell-google-genai-client 0.2.0 — rewrite design

Date: 2026-09-02
Status: approved design, awaiting implementation plan
Origin: iconnect/hermes#2613, iconnect/atlas#8343 (comment 5493503398)

## 1. Why

The upstream library (sonowz) is unmaintained. Hermes depends on it to call
Gemini through Vertex AI (`generateContent`) and through the Gemini API
(Files API). Two problems drive this rewrite:

1. **`Maybe` everywhere.** Every field of every generated record is `Maybe`.
   Root cause: Google's Discovery document (the only machine-readable source;
   Google publishes no OpenAPI spec) carries no `required`/`nullable` keys.
   Required-ness exists only as description prefixes `Required.`, `Optional.`,
   `Output only.`. On top of that, Gemini speaks proto3 JSON: scalar fields at
   their default value (`0`, `""`, `false`, `[]`) are omitted from the wire.
   `cachedContentTokenCount` is legitimately absent when zero. The right
   Haskell shape is therefore "non-`Maybe` with default on absent" for
   response scalars, not "`Maybe` everywhere" and not "required everywhere".
2. **Opaque generation pipeline.** The input file `genai_openapi.json` was never
   committed, the generator needs a JVM, and the generated runtime (Core,
   Client, MimeTypes, Logging × 2 backends) is 1.1k lines of generic plumbing
   nobody here understands.

Goal: semi-production library owned by iconnect, deterministic regeneration,
tight types, Katip logging, CI on GHC 9.6.7 and 9.10.3.

## 2. Decisions taken (do not re-open)

| Topic | Decision |
|---|---|
| Type source | Gemini API Discovery doc, `generativelanguage` `v1beta`. Vertex handled by URL routing only. |
| Generator | Own Haskell executable `genai-codegen` in this repo. No openapi-generator, no Java. |
| Runtime | Replace haskell-http-client runtime with a hand-written minimal client. |
| Endpoint scope | Allowlist (models, files, cachedContents). Extending = editing one list. |
| Field naming | Prefixed, as today: `usageMetadataPromptTokenCount`, `mkUsageMetadata`. |
| Streaming | Design hook only (`alt` field on `Request`). No implementation. |
| Package | Same name, version `0.2.0`, `GenAI.Client.*` modules. Not published to Hackage. |
| Logging | Katip, unconditional. `monad-logger` and the `UseKatip` flag go away. |
| Nix | Removed. Not a priority. |
| Lenses | Not generated. Hermes has two uses; they pattern-match instead. |

## 4. Spec acquisition

`scripts/update-spec.sh`:

```sh
#!/usr/bin/env sh
set -eu
url='https://generativelanguage.googleapis.com/$discovery/rest?version=v1beta'
out="$(dirname "$0")/../spec/generativelanguage-v1beta.json"
curl -fsSL "$url" -o "$out"
printf 'revision: %s\n' "$(jq -r .revision "$out")"
```

Workflow to bump: run script, `cabal run -f codegen genai-codegen`, build, run
tests, review diff of generated files, commit spec + generated files together.
The revision (`.revision`, e.g. `20260830`) is embedded in the generated
header, so `git log` on `Model.hs` shows which revision produced it.

## 5. Codegen

### 5.1 Input model (Discovery document)

Fields the codegen reads. Everything else ignored.

```
.revision                                    : string
.schemas.<Id>                                : Schema
  .id, .type ("object"), .description
  .properties.<name>                         : Property
    .type      ("string"|"integer"|"number"|"boolean"|"array"|"object"|"any")
    .format    ("int32"|"uint32"|"int64"|"uint64"|"float"|"double"|"byte"|
                "google-datetime"|"date-time"|"google-duration"|"google-fieldmask")
    .$ref      (schema id; mutually exclusive with .type)
    .items     (Property, when type == array)
    .enum      [string], .enumDescriptions [string], .enumDeprecated [bool]
    .additionalProperties (Property)         (map-typed object)
    .description, .readOnly, .deprecated
.resources.<name>.methods.<name>             : Method   (nested resources: .resources.<a>.resources.<b>…)
  .id          e.g. "generativelanguage.models.generateContent"
  .path        e.g. "v1beta/{+model}:generateContent"
  .flatPath    e.g. "v1beta/models/{modelsId}:generateContent"
  .httpMethod
  .parameters.<name> { .type, .format, .location ("path"|"query"), .required, .pattern, .description, .repeated }
  .parameterOrder [string]
  .request.$ref, .response.$ref
  .supportsMediaUpload, .mediaUpload.protocols.resumable.path
```

The implementer must verify these against the vendored file; the format above
is from Google's Discovery Service v1 reference and from the 0.1.0 converted
`openapi.yaml`.

allowlist is a codegen error.

### 5.3 Direction analysis

For every emitted schema compute `Direction`:

- Seed: method `.response.$ref` schemas are *response-reachable*; method
  `.request.$ref` schemas are *request-reachable*.
- Propagate along properties: a `$ref` (directly or via `items` /
  `additionalProperties`) inherits the parent's reachability, **except** that a
  property whose description starts with `Output only.` propagates only
  response-reachability.
- `Direction = ResponseOnly` if response-reachable and not request-reachable;
  otherwise `Bidirectional`. (Request-only schemas are treated as
  Bidirectional; nothing is gained by distinguishing them.)

Expected outcome, to be asserted by the implementer as a sanity check:
`UsageMetadata`, `Candidate`, `GenerateContentResponse`, `ModalityTokenCount`,
`PromptFeedback`, `CitationMetadata` are `ResponseOnly`; `Content`, `Part`,
`Blob`, `FileData`, `GenerationConfig`, `Schema`, `File`, `CachedContent`
are `Bidirectional`.

### 5.4 Field typing rules

`isRequired p = "Required." ` is a prefix of `p.description` (after trimming).

| Property shape | ResponseOnly schema | Bidirectional schema |
|---|---|---|
| `$ref M` | `Maybe M`; required → `M` | same |
| `array` of `T` | `[T]` | `[T]` |
| `object` + `additionalProperties: {type: any}` or no `properties`/`additionalProperties` | `Aeson.Object` | same |
| `object` + typed `additionalProperties` | `Map Text T` | same |
| `any` | `Aeson.Value` | same |
| `string` (no enum, no special format) | `Text`, absent → `""` | `Maybe Text`; required → `Text` |
| `string` + `enum` | `E` (enum type), absent → `*Unspecified` ctor if the enum has a value ending in `_UNSPECIFIED`, else `Maybe E` | `Maybe E`; required → `E` |
| `string` format `int64`/`uint64` | `Int64`, absent → `0` | `Maybe Int64`; required → `Int64` |
| `string` format `byte` | `Base64Bytes`, absent → empty | `Maybe Base64Bytes`; required → `Base64Bytes` |
| `string` format `google-datetime`/`date-time` | `Maybe UTCTime` (no sane default) | `Maybe UTCTime`; required → `UTCTime` |
| `string` format `google-duration`/`google-fieldmask` | `Text`, absent → `""` | `Maybe Text`; required → `Text` |
| `integer` (`int32`/`uint32`) | `Int`, absent → `0` | `Maybe Int`; required → `Int` |
| `number` (`float`/`double`) | `Double`, absent → `0` | `Maybe Double`; required → `Double` |
| `boolean` | `Bool`, absent → `False` | `Maybe Bool`; required → `Bool` |

Rationale for Bidirectional scalars staying `Maybe`: proto3 `optional` scalars
have explicit presence and `temperature: 0` must be sendable; the Discovery
document cannot tell `optional float` from plain `float`.

Override hook: `overrides :: Map (Text, Text) Rule` in `Analyse.hs`, keyed by
(schema id, property name), where `Rule = ForceMaybe | ForceDefault | ForceRequired`.
Starts empty. Used only when a real response contradicts the rules above;
every entry needs a comment with the evidence.

### 5.5 Naming

- Type and constructor: schema id verbatim (`UsageMetadata`).
- Field: `lowerFirst(schemaId) ++ upperFirst(propertyName)`
  (`usageMetadataPromptTokenCount`). Property names containing `_` or `-`
  are camelised first.
- Smart constructor: `mk<SchemaId>`, positional arguments = required fields in alphabetical
  property-name order (matching emission order, section 5.9); all other fields default (`Nothing`, `[]`, proto3
  default, `mempty` for `Object`/`Map`).
- Enum type: `<SchemaId><UpperFirst propertyName>`, e.g. `CandidateFinishReason`,
  `FileState`, `HarmCategory`… **Exception:** when the same enum value list
  appears in more than one schema, no dedup is attempted; each gets its own
  type. Boring beats clever.
- Enum constructors: `<EnumType><PascalCase value>`:
  `FINISH_REASON_UNSPECIFIED` → `CandidateFinishReasonFinishReasonUnspecified`.
  Long but collision-free and mechanical. Plus `<EnumType>Unknown Text` catch-all.
- Haskell keyword or clashing names cannot arise for fields (prefixed) or
  constructors (prefixed). Type names clashing with Prelude (`Maybe`, `Either`)
  do not occur in this spec; codegen errors if they do.
- Haddock: schema description on the type; property description on each
  field; `enumDescriptions` on each constructor. Escape `'`, `"`, `@`, `\`
  per Haddock rules; keep `Output only.`/`Required.` prefixes visible.

### 5.6 Emitted `Model.hs`

Per schema:

```haskell
-- | Metadata on the generation request's token usage.
data UsageMetadata = UsageMetadata
  { usageMetadataPromptTokenCount :: !Int
    -- ^ Number of tokens in the prompt. …
  , usageMetadataCachedContentTokenCount :: !Int
  , usageMetadataCandidatesTokenCount :: !Int
  , usageMetadataToolUsePromptTokenCount :: !Int
  , usageMetadataThoughtsTokenCount :: !Int
  , usageMetadataTotalTokenCount :: !Int
  , usageMetadataPromptTokensDetails :: ![ModalityTokenCount]
  , usageMetadataCacheTokensDetails :: ![ModalityTokenCount]
  , usageMetadataCandidatesTokensDetails :: ![ModalityTokenCount]
  , usageMetadataToolUsePromptTokensDetails :: ![ModalityTokenCount]
  } deriving stock (Show, Eq, Generic)

mkUsageMetadata :: UsageMetadata
mkUsageMetadata = UsageMetadata 0 0 0 0 0 0 [] [] [] []

instance FromJSON UsageMetadata where
  parseJSON = withObject "UsageMetadata" $ \o -> UsageMetadata
    <$> o .:? "promptTokenCount" .!= 0
    <*> …
instance ToJSON UsageMetadata where
  toJSON UsageMetadata{..} = object $ catMaybes
    [ Just ("promptTokenCount" .= usageMetadataPromptTokenCount)
    , …                                   -- Maybe fields: fmap (k .=) ; lists: omit when null
    ]
```

Encoding rules: omit `Nothing`; omit `[]`; emit every other field as-is
(including `0`/`""`/`False` in ResponseOnly types — harmless, and keeps
`decode . encode == id`). Empty `Object`/`Map` emitted as `{}`.

Enum instances: `FromJSON` matches known strings else `Unknown t`;
`ToJSON` inverse, `Unknown t` → `t`.

`Int64` decoding: accept JSON string (canonical proto3) or number; encode as
string. Implement once in `Types.hs` as `newtype Int64Json` **or** as two
helper functions `parseInt64 :: Value -> Parser Int64` /
`encodeInt64 :: Int64 -> Value` used by generated code. Prefer helpers; the
public field type stays plain `Int64`.

`Base64Bytes`: `newtype Base64Bytes = Base64Bytes ByteString` in `Types.hs`,
JSON as standard base64 (`base64-bytestring` `encode`/`decode`; accept URL-safe
alphabet on decode as well, Google emits standard).

`UTCTime`: aeson's built-in RFC3339 instances.

Deprecated properties (`.deprecated: true`) are still emitted, Haddock notes
`Deprecated.`.

### 5.7 Emitted `API.hs`

Per allowlisted method, one function returning `Request <Response>`:

```haskell
-- | POST v1beta/{+model}:generateContent
generateContent :: Text -> GenerateContentRequest -> Request GenerateContentResponse
generateContent model body = Request
  { reqMethod   = "POST"
  , reqResource = ModelMethod model ":generateContent"
  , reqQuery    = []
  , reqBody     = Just (toJSON body)
  , reqAlt      = Nothing
  }

listModels :: ListModelsQuery -> Request ListModelsResponse
data ListModelsQuery = ListModelsQuery { listModelsPageSize :: Maybe Int, listModelsPageToken :: Maybe Text }
mkListModelsQuery :: ListModelsQuery

getFile :: Text -> Request File                 -- "files/abc-123"
deleteFile :: Text -> Request ()                -- Empty response → ()
patchCachedContent :: Text -> PatchCachedContentQuery -> CachedContent -> Request CachedContent
```

Rules:
- Function name: method name; if method name is a bare verb (`list`, `get`,
  `delete`, `create`, `patch`) → `<verb><SingularOrPluralResource>` as shown
  (`listModels`, `getModel`, `getFile`, `listFiles`, `deleteFile`,
  `createCachedContent`, `getCachedContent`, `listCachedContents`,
  `patchCachedContent`, `deleteCachedContent`). Hardcode this small table in
  `Analyse.hs`; anything not in the table falls back to `<verb><Resource>`.
- Path params: `Text`, in `parameterOrder`. The Discovery path
  `v1beta/{+model}:generateContent` with pattern `^models/[^/]+$`: the
  function accepts either `models/foo` or bare `foo`; `Run.hs` normalises
  (section 6.3). Other resources (`files/{+name}`, `cachedContents/{+name}`)
  take the full resource name (`files/abc`) as Google returns it; no
  normalisation.
- Resource classification: path starts with `v1beta/{+model}` → `ModelMethod`;
  otherwise `RawPath` with the path *minus* the `v1beta/` prefix and with
  params substituted (the version is supplied by `Backend.baseUrl`).
- Query params: if the method has any `location: query` parameters, emit a
  `<Fn>Query` record of `Maybe`s + `mk<Fn>Query`; else none. Rendered to
  `reqQuery` dropping `Nothing`. `$.xgafv`, `alt`, `key`, `access_token`,
  `upload_protocol`, `uploadType`, `prettyPrint`, `quotaUser`, `callback`,
  `fields`, `oauth_token` (Discovery global params) are excluded.
- Response schema `Empty` → `Request ()`; `Run.hs` treats `()` as "ignore body".
- `streamGenerateContent` emitted as a normal function; `reqAlt = Just "sse"`.
  Documented as not runnable with `runRequest` until streaming lands
  (`runRequest` returns `UnsupportedOperation` for `reqAlt = Just _`).

### 5.8 Emitted `tests/Instances.hs`

`Arbitrary` for every emitted type. Enums: `elements` over known constructors
only (never `Unknown`). `Aeson.Object`/`Value`: generate small flat objects of
strings/numbers to keep the property fast. `UTCTime`: whole seconds only
(RFC3339 round-trip of picoseconds is lossy in aeson).

### 5.9 Codegen CLI and determinism

`genai-codegen --spec spec/generativelanguage-v1beta.json --lib lib --tests tests`
writes the three generated files. Output must be byte-identical across runs
and machines: iterate schemas, properties, enum values and methods in
alphabetical order (aeson `KeyMap.toAscList`), never in JSON document order.
No timestamps in output, only the revision.

## 6. Runtime client

### 6.1 `Types.hs`

```haskell
data Backend
  = GeminiApi { backendBaseUrl :: !Text }
  | VertexAi  { backendBaseUrl :: !Text, vertexProject :: !Text, vertexLocation :: !Text }
  deriving (Show, Eq)

geminiApi :: Backend                          -- GeminiApi "https://generativelanguage.googleapis.com/v1beta"
vertexAi  :: Text -> Text -> Backend          -- project location; baseUrl derived:
                                              --   location == "global" → "https://aiplatform.googleapis.com/v1"
                                              --   otherwise            → "https://<location>-aiplatform.googleapis.com/v1"
                                              -- caller may override backendBaseUrl afterwards (hermes config)

data Auth
  = ApiKey !Text                -- sent as header x-goog-api-key
  | BearerToken (IO Text)       -- run per request; caller handles refresh/caching
  | NoAuth

data Env = Env
  { envManager :: !Manager
  , envBackend :: !Backend
  , envAuth    :: !Auth
  , envLogEnv  :: !Katip.LogEnv        -- Katip.initLogEnv "genai" "…" with no scribes = silent
  }

data Resource
  = ModelMethod !Text !Text     -- model, ":verb"      (Vertex-routable)
  | RawPath     !Text           -- "files/abc", "cachedContents?pageSize=…" NOT included; query separate
  deriving (Show, Eq)

data Request a = Request
  { reqMethod   :: !ByteString          -- "GET"/"POST"/"PATCH"/"DELETE"
  , reqResource :: !Resource
  , reqQuery    :: ![(Text, Text)]
  , reqBody     :: !(Maybe Aeson.Value)
  , reqAlt      :: !(Maybe Text)        -- streaming hook; Just "sse" unsupported for now
  }

data GenAIError
  = HttpError !HttpException
  | ApiError { apiStatus :: !Int, apiGoogleStatus :: !(Maybe Status), apiRawBody :: !LBS.ByteString }
  | DecodeError !Text !LBS.ByteString
  | UnsupportedOnBackend !Text          -- RawPath request against VertexAi
  | UnsupportedOperation !Text          -- reqAlt = Just _
  deriving (Show)
instance Exception GenAIError

newtype Base64Bytes = Base64Bytes { unBase64Bytes :: ByteString } deriving (Show, Eq)
```

`Status` is the generated Google RPC status (`code`, `message`, `status`,
`details :: [Object]`) if present in the emitted closure; otherwise defined
here by hand with those four fields.

### 6.2 `Run.hs`

```haskell
runRequest    :: FromJSON a => Env -> Request a -> IO (Either GenAIError a)
runRequestRaw :: Env -> Request a -> IO (Either GenAIError (Response LBS.ByteString))
```

`runRequest` = `runRequestRaw` then: `2xx` → decode body (`()` responses skip
decoding); anything else → `ApiError` with body decoded as `{"error": Status}`
when possible. `HttpException` caught → `HttpError`. Not caught: async
exceptions, anything else.

Headers: `Content-Type: application/json` when body present, `Accept:
application/json`, auth header, `User-Agent: haskell-google-genai-client/0.2.0`.
No retries. No timeout handling beyond the `Manager`'s.

Logging (Katip, namespace `genai`): after each request `DebugS`
`"<METHOD> <url> -> <status> <ms>ms"`; on `ApiError` `ErrorS` with status and
`Status.message`; on `HttpError` `ErrorS` with the exception shown. URLs never
contain credentials (API key is a header). Bodies never logged.

### 6.3 URL building

```
GeminiApi base:
  ModelMethod m v  → base <> "/models/" <> stripModelsPrefix m <> v
  RawPath p        → base <> "/" <> p
VertexAi base proj loc:
  ModelMethod m v  → base <> "/projects/" <> proj <> "/locations/" <> loc
                        <> "/publishers/google/models/" <> stripModelsPrefix m <> v
  RawPath _        → Left (UnsupportedOnBackend p)
query: reqQuery rendered with http-types renderQuery; percent-encoded.
```

`stripModelsPrefix` removes one leading `models/` if present. Model names
containing `/` after stripping (tuned models `tunedModels/x`) are passed
through untouched — `stripModelsPrefix "tunedModels/x" == "tunedModels/x"`
and Gemini path becomes `/models/tunedModels/x`, which is wrong; document
that tuned models are out of scope rather than special-casing.

### 6.4 `Files.hs`

```haskell
data UploadSpec = UploadSpec
  { uploadMimeType    :: !Text
  , uploadDisplayName :: !(Maybe Text)
  , uploadBytes       :: !LBS.ByteString
  }
uploadFile :: Env -> UploadSpec -> IO (Either GenAIError File)
```

Resumable protocol (https://ai.google.dev/gemini-api/docs/files):

1. `POST <uploadBase>/files` where `uploadBase` = `backendBaseUrl` with
   `/v1beta` replaced by `/upload/v1beta` (i.e. insert `upload/` before the
   version segment). Headers: `X-Goog-Upload-Protocol: resumable`,
   `X-Goog-Upload-Command: start`, `X-Goog-Upload-Header-Content-Length: <n>`,
   `X-Goog-Upload-Header-Content-Type: <mime>`, `Content-Type: application/json`,
   auth. Body: `CreateFileRequest` with `File{displayName}`.
   Read response header `x-goog-upload-url`; missing → `DecodeError`.
2. `POST <upload-url>` headers `Content-Length: <n>`, `X-Goog-Upload-Offset: 0`,
   `X-Goog-Upload-Command: upload, finalize`, body = bytes. Response body is
   `CreateFileResponse { file :: Maybe File }`; `Nothing` → `DecodeError`.

`VertexAi` backend → `UnsupportedOnBackend "files"`. Whole payload is sent in
one chunk (files ≤ 2 GB per Google, but we hold it in memory; document).
Polling `File.state` until `ACTIVE` is the caller's job.

### 6.5 `GenAI/Client.hs`

Re-exports `Types`, `Run`, `Files`, `Model`, `API`. Hides nothing.

## 7. Tests

`tests/Test.hs` runs:

1. **Round-trip property** (generated `Instances.hs`): for every emitted type
   `T`, `decode (encode x) == Just x`. `modifyMaxSize (const 8)`.
2. **Fixtures** (`tests/Fixtures.hs`, JSON files under `tests/fixtures/`).
   Each decodes without error and asserts a few fields:
   - `generate_content_basic.json` (README sample): `usageMetadataCachedContentTokenCount == 0`,
     `usageMetadataThoughtsTokenCount == 0`, `candidateFinishReason == …Stop`, one candidate.
   - `generate_content_thinking.json`: `thoughtsTokenCount > 0`, `promptTokensDetails` non-empty.
   - `generate_content_unknown_finish_reason.json`: hand-edited `finishReason: "SOMETHING_NEW"` →
     `CandidateFinishReasonUnknown "SOMETHING_NEW"`.
   - `error_400.json`, `error_429.json`: `{"error": {...}}` decodes to `Status` with code/message.
   - `file.json`: `sizeBytes` as JSON string decodes to `Int64`; `state == FileStateActive`.

## 12. Open risks

- Direction analysis may classify a schema as `ResponseOnly` that Google also
  accepts in requests in a future revision (e.g. if `UsageMetadata` gains a
  request use). Consequence: fields flip to `Maybe` on regeneration, a
  compile-time break downstream. Acceptable; that is what the drift check
  and a version bump are for.
- `Text` default `""` for absent response strings hides absence. Accepted for
  ResponseOnly types; use `overrides` if a specific field needs `Maybe`.
- Enum constructor names are long (`CandidateFinishReasonFinishReasonStop`).
  Accepted for mechanical safety; a future pass may strip the redundant
  `FINISH_REASON_` prefix when all values share it. Not now.
